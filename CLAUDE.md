## Updating the Azure Funding Advisor from a new Microsoft guide

The user will attach new editions of:
- **Microsoft Commercial Partner Incentives Guide** (`cpi`, primary source, ~365 pages)
- **FY27 Frontier Accelerate MCI summary deck** (`mci`, short summary incl. India Market C tables)

Procedure:
1. Copy each PDF into its own empty scratch folder, then `python3 -I scripts/extract-guide-text.py <pdf> --toc` and `... <pdf> <scratch>/cpi.txt`. Never commit guide text (it is Microsoft Confidential).
2. Map guide sections to data:
   - Cloud & AI Platforms pre-sales / post-sales / SMB → `src/data/incentives/azure.json` (`lane`: `pre-sales`, `post-sales`; `track`: `specialized`, `smb`)
   - Security Sentinel / Defender for Cloud deployment accelerators → `azure.json` (`lane: two-stage`, payout = Stage 1, `stage2` = Stage 2, markets `ABC`)
   - Marketplace → `azure.json` (`lane: marketplace`)
   - CSP Azure, COCP, Enterprise Azure lever, performance rules → `azure.json` top-level `csp`, `cocp`, `enterprise`, `performance`
   - Copilot, AI-Ready Productivity, Business Processes, Security seat engagements → `src/data/incentives/modern-work.json` (`family`, `lane`)
   - Biz Apps Presales Advisor → `modern-work.json` `cpor`; M365 / D365 CSP levers → `modern-work.json` `csp`
   - Market country lists → `markets.json` (Azure uses A/B; MW & Security use A/B/C)
3. Size bands: `min` is the lower bound, exclusive unless `minInclusive: true` (first band is inclusive). Seat-based bands are inclusive thresholds. Keep `source.pages` accurate.
4. New partner credentials go in `credentials.json` first (the validator rejects unknown ids). New Azure services go in `src/data/catalog/azure-services.json` with tags (legend in its `$comment`).
5. Record conflicts between the two documents, or obvious typos, in `meta.json` → `discrepancies`, and set `lastReviewed`, `edition`, `investmentTerm`.
6. Only touch `src/lib/advisor/*` when a programme introduces a new rule shape (e.g. a new workload-share test). Keep the engine data-driven.
7. Run `npm run validate:data && npx tsc --noEmit && npm run build`, then exercise `/clouds/azure/sales` in the browser with a known example from the guide (e.g. Cowork worked example → 62 MAU → $3,100; Databases L Market B → $120,000).

## Other conventions
- Page copy for each cloud × service lives in `src/content/clouds/<cloud>.ts`; keep the expert, specific tone and avoid unverifiable statistics or client claims.
- Templates are generated by `scripts/artefacts/build.py` (profiles per cloud in `profiles.py`); regenerate after edits, which also refreshes `src/data/artefacts.json`.
- Design tokens are CSS variables at the top of `src/app/globals.css` (paper / ink / vermilion, IBM Plex). Don't introduce gradients or new font families.
